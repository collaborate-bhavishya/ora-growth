# ora-growth

A Claude-run LinkedIn content system for the Indian D2C ecosystem.

| Day | Series |
|---|---|
| Tue | **AI for the D2C ___** — how AI changes a specific D2C role |
| Wed | **Brand Teardown** — a great Indian D2C product, category by category |
| Fri | **Founder Friday** — celebrating a founder's recent milestone |

## How to use
- "Run this week's posts" → `weekly-run` produces 3 fact-checked drafts in `pipeline/<week>/drafts/`.
- Review and edit, then "approve Tue/Wed/Fri" → `schedule-buffer` schedules them in Buffer.
- After publishing: add manual founder tags, attach the visual, post sources as first comment.

See `strategy/strategy.md` for the full strategy.
