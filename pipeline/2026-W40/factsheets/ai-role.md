## Workflow table (opinion; tool names sourced above)
| Task | Before | With AI | Human owns |
|---|---|---|---|
| Monday reporting | Exports → Sheets → deck, 3–4 h | Ads/Analytics Advisor + LLM on CSVs drafts pivots, anomalies, narrative | Reconcile platform ROAS vs Shopify/MER; check every number |
| Creative testing | 4–6 ads/week, design-bound | Advantage+ creative, Asset Studio, Brand Memory; Andromeda rewards diversity | Pick concepts (angle/offer/persona), approve claims, switch off off-brand auto-enhancements |
| Hook ideation | Manual brainstorm | LLM clusters reviews/comments → 30+ hooks, Hinglish UGC scripts | Cultural nuance, humour, founder sign-off |
| Structure | Many interest/LAL ad sets | Advantage+ sales, AI Max, PMax, broad | Consolidation, brand vs non-brand, new vs returning |
| Budget pacing | Daily sheet checks | CBO/Smart Bidding + LLM-built pacing alerts | Cash, inventory, festive front-loading |
| Competitor research | Scroll Ad Library | Ad Library + LLM summary of angles/offers | Positioning, not copying |
| Landing page CRO | Dev backlog | LLM copy variants/hypotheses; AI Max URL expansion | Claims/legal (esp. beauty/health), test design |
| Attribution | GA4 last-click | Meridian MMM with LLM help | Priors, holdouts, honesty with CFO |
| Marketplace/q-comm ads | Separate dashboards | LLM merges exports, drafts keyword/negative lists | Dark-store availability, SKU margin |
